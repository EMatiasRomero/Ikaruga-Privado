Cómo usar esta herramienta
  • Plantillas: escribí tus mensajes usando {nombre}, {idioma} y {rep}. Se completan solos con los datos de cada contacto.
  • {nombre} usa solo el primer nombre aunque hayas cargado el nombre completo (ej: "Alejandro David Mancuello" → el mensaje dice "Alejandro"). El resto del nombre solo se ve en la lista, para identificar bien a cada persona.
  • Si falta un dato: sin nombre, el mensaje dice "qué tal"; sin idioma, dice "un idioma" — así el mensaje nunca queda roto.
  • Tandas: cada vez que importás desde tu planilla, ponele un nombre a esa tanda (por defecto usa la fecha y hora). Después podés filtrar la lista de contactos por tanda para no mezclarlas.
  • Pendientes / Enviados: al tocar "Abrir WhatsApp" el contacto pasa solo a "Enviado", con la fecha y la plantilla que usaste. Si necesitás corregirlo, usá el botón "Marcar pendiente/enviado" de cada tarjeta.
  • ☁️ Sincronizado (arriba a la derecha) significa que lo que cargues acá se va a ver igual en cualquier otro dispositivo donde abras este mismo link.
